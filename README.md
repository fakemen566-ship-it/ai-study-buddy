# AI Study Buddy

A small starter project for students who want help turning study notes into clearer revision material.

## What it does
- Lets you paste notes into a simple web page.
- Creates a structured prompt for an AI assistant to make a summary, flashcards, or a practice quiz.
- Keeps the workflow simple and easy to customize.

**Important:** This starter does not call an AI API or send your notes anywhere. It prepares a prompt you can copy into an AI assistant.

## Run it
No installation needed:
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Paste your notes, choose an output type, and click **Generate prompt**.
4. Copy the prompt into the AI assistant you use.

## Project status
Early prototype. It currently builds prompts locally in the browser. Planned improvements include better note organization, editable flashcards, accessibility improvements, and user feedback.
